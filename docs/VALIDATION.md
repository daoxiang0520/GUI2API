# 验证范围

当前主分支保留 0.5.0 协议基线，并包含 2026-10-26 的本地绑定缓存更新。独立目录验证结果：

- GUI2API Python 全量回归：309 项。
- 独立 dsh-winbot 的开发 SDK 与本机安装 SDK：各 21 项，包括额外的独立目录后端定位测试；注册 24 个 DSH 工具。
- MCP stdio：44 个工具，真实工具管线、对象后置条件与陈旧引用拦截。
- UIA3 / MSAA / Win32 自建窗口、独立 Chromium DOM 的缓存基准，以及真实 QQ 当前页面的只读观察。
- 结构/标签/方法变化、可靠性降级、事件监听丢失、缓存过期、模糊选择器、标签值/截断值、后置条件失败隔离，以及原有输入前 guard、焦点与遮挡检查。
- PowerShell 语法、公开 Markdown 链接、发布文件清单和校验值。

具体当前结果以本提交 PUBLICATION.json 为准，性能数字与限制见 [CACHE_BENCHMARKS.md](CACHE_BENCHMARKS.md)。测试没有调用 DeepSeek 模型，也没有重新验收所有真实应用的业务任务。

0.5.0 基线还保留自建 Windows 窗口的菜单恢复、单次 Enter、隔离控制台读取、Qt 和业务对象桥等历史验证。缓存更新不会把这些历史结果扩大为对所有应用的覆盖保证。

原始本机报告、用户 profile、人格/记忆、聊天、缓存、浏览器 profile 和凭据均排除。控件标签不证明用途，动作返回不代表业务完成，历史关系不证明因果。
