# 验证范围

当前源码保留 0.5.0 包基线，包含绑定缓存和 2026-10-26 新增的多模态资源层。独立发布目录验证：

- Python 全量回归 334 项，其中资源层 25 项。
- 独立 dsh-winbot 的开发 SDK 与本机桌面版 SDK 各 25 项，包含独立目录后端定位；28 个 DSH 工具。
- MCP 共 48 个工具；既有控件/探索管线和新资源 stdio 管线均验证。
- 独立无头 Chromium、本机自建 HTTP 页面：图片、音频、视频、PDF、二进制、文本、选中 File 的字节和 SHA256 一致。WebM 在浏览器中确认可解码。
- MCP 图片/音频内容块、视频/文档引用、artifact URI、字节范围读取、显式渲染、来源变化拒绝、禁止自动录制与跟随重定向。
- JavaScript/Python 语法、PowerShell AST、公开链接、内容清单与 Git blob 校验值。

原生 GDI 渲染读取尚未完成实窗验收：本机自建测试窗口的前台激活被 Windows 拒绝，测试在读取像素前停止，没有放宽焦点或遮挡条件。

QQ 已只读观察到“消息列表”祖先下的 Image/图片节点，说明媒体占位可以存在于控件树。当前尚未自动整理为逐条消息记录，合并转发卡片、文件卡片、语音/视频消息及统一的原文件读取未验收；这些边界不被浏览器样例的通过覆盖。

DSH 图片输出使用真实 SDK 契约的测试附件服务，验证 ToolRegistry 内容保留，不调用模型、不证明生产模型支持图片。当前 DSH 的音视频、文档保留文件引用，未实现 ASR、视频理解或文档正文提取。

缓存基准与历史范围保留在 [CACHE_BENCHMARKS.md](CACHE_BENCHMARKS.md)。本次准确结果见 PUBLICATION.json。测试没有安装插件、改 profile、用户人格/记忆或重启生产 Host。

原始聊天、账号、个人路径、控件快照、浏览器 profile、模型凭据和本机原始报告均不纳入公开仓库；仅保留自建样例、源码与汇总说明。
